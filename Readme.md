# Contract Analyzer

**Status:** 🚧 Under Development

Contract Analyzer is an AI-powered tool designed to help users quickly analyze and extract key information from contracts. The project is still in progress, but the current implementation demonstrates the core features and the potential of the tool.

## Features (Planned / In Progress)

- **Contract Upload:** Upload PDF or text contracts for analysis.
- **Clause Extraction:** Identify and extract important clauses automatically.
- **Risk Assessment:** Highlight potential risks or unusual terms.
- **Summarization:** Generate a concise summary of the contract.
- **Search & Query:** Ask questions about the contract and get AI-assisted answers.
- **Multi-format Support:** PDF, DOCX, TXT (future support for more formats planned).
- **Dashboard (Planned):** Visualize contract insights and summaries.
